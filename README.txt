WEBSITE HADIAH — FOR MY DEAR STESSA ABIGAIL

CARA MEMBUKA:
1. Klik dua kali file index.html (atau buka dengan Chrome, Safari, atau Edge).
2. Pilih "Rangkai Buket" untuk menambahkan 7 mawar, 7 uang Rp100.000, dan pita.
3. Atau pilih "Puzzle Foto" untuk menyusun 9 potongan foto referensi.
4. Setelah selesai, klik "Buka kejutan" / selesaikan puzzle untuk melihat hadiah.
5. Klik "Simpan kartu hadiah" bila ingin menyimpan kartu sebagai gambar PNG.

BERBAGI ONLINE:
Unggah index.html ke layanan hosting situs statis, misalnya Netlify Drop atau GitHub Pages.
Website ini cukup menggunakan satu file HTML dan tidak membutuhkan internet atau gambar terpisah.
Foto asli sudah disertakan dalam file website. Tidak diperlukan instalasi aplikasi.
